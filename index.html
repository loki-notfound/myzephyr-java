zephyr-java

Java bindings for the Zephyr Protocol wallet core, for Android (AAR) and for desktop and server JVMs (JAR), built from the security-hardened forks of zephyr-backports. Version 2.3.0-sec.2-java.2.

Not affiliated with ZephyrProtocol. An independent project. Report Zephyr vulnerabilities to the ZephyrProtocol team, not here.

Android (Gradle, Kotlin DSL)

repositories {
    maven { url = uri("https://loki-notfound.github.io/myzephyr-java/maven") }
}

android {
    packaging { resources.excludes += "/META-INF/DEPENDENCIES" }
}

dependencies {
    implementation("io.github.loki-notfound:zephyr-java-android:2.3.0-sec.2-java.2")
}

Desktop and server (Maven)

<repositories>
  <repository>
    <id>zephyr-java</id>
    <url>https://loki-notfound.github.io/myzephyr-java/maven</url>
  </repository>
</repositories>

<dependency>
  <groupId>io.github.loki-notfound</groupId>
  <artifactId>zephyr-java</artifactId>
  <version>2.3.0-sec.2-java.2</version>
</dependency>

Older releases

The Maven repository keeps every release, so a build can stay on an older version with the same repository line. The Javadoc on this site is that of version 2.3.0-sec.2-java.2 only; an older version's Javadoc is its zephyr-java-<version>-javadoc.jar, in the repository and among the files of its release.

  • 2.3.0-sec.2-java.1 (release): io.github.loki-notfound:zephyr-java-android:2.3.0-sec.2-java.1, io.github.loki-notfound:zephyr-java:2.3.0-sec.2-java.1
